# Vamos 2.0 — 从零到母语水平的西班牙语 iOS 应用

以**西班牙本土西语（Castellano）**为准：咬舌音 [θ]、vosotros、西班牙用词和口语从第一课就开始。界面中文，iOS 16+，纯 SwiftUI，无第三方依赖。

## 两个部分

**离线就能用的 A1 入门**：24 节手写课（6 个单元），讲解、例句、发音提示、7 种练习题全部内置。

**联网 + AI 带你到 C2**：A2–C2 共 140 节课，按《塞万提斯学院课程大纲》（PCIC）和 CEFR 编排。每节课第一次打开时由 AI 按大纲生成（讲解、10–14 条地道例句、8 道练习），保存在手机上，之后离线可用。觉得某节内容不好可以一键重新生成。

| 级别 | 单元 |
|---|---|
| A1 入门 | 发音与问候 · 我是谁 · 日常生活 · 在西班牙 · 日常作息 · 城市与生活 |
| A2 初级 | 我的经历 · 过去的样子 · 健康与运动 · 住房与城市 · 生活与服务 · 计划与未来 |
| B1 中级 | 情感与关系（虚拟式）· 讲述与转述 · 工作 · 旅行与自然 · 观点与讨论 · 文化与休闲 |
| B2 中高级 | 虚拟式进阶 · 社会议题 · 职场进阶 · 媒体与语言 · 假设与推测 · 表达与文学 |
| C1 高级 | 语法精细 · 学术与职业表达 · 地道口语与俚语 · 社会与文化 · 词汇精度 |
| C2 精通 | 语用与语感 · 谚语与典故 · 方言与变体 · 高级写作 · 像母语者一样 |

## 功能

- **学习**：级别切换、闯关路径；每课「讲解 → 新词句（可跟读打分）→ 练习 → 小结」；学过 A1 可以做**分级测试**直接跳级
- **练习题**：看西选中、看中选西、听音辨词、听写、选词填空、拖词组句、打字翻译、配对、**口语题**（语音识别逐词打分）
- **对话**：AI 陪练，20 个按级别分的情景（点单、看房、面试、商务谈判、谈薪、马德里俚语闲聊、电台 tertulia……）+ 自由聊天；支持语音输入，**每句话自动纠错**并给出更地道的说法；对方的话可朗读、翻译、点词查词典；卡住了可以让 AI 给出可选的回答
- **探索**
  - 查词 · 翻译：单词 → 词典（西班牙音标、释义、例句、西班牙用法、搭配）；句子 → 精读分析；中文 → 地道西语说法
  - 动词变位：11 个时态/语气全表（缓存后离线可看）
  - 阅读：西班牙媒体 RSS 新闻（可自己加源），自动提取正文，**点任何单词查词**，全文朗读，AI 精读（摘要 + 生词 + 文化背景）；AI 分级读物 + 理解题
  - 听力：AI 生成真实感对话，双声音朗读、可慢速、隐藏原文、理解题
  - 发音练习：西班牙口音专项（θ/s、j、r/rr、软 d、ñ）+ 经典绕口令 + 已学内容，跟读逐词打分
  - 写作批改：AI 出题，DELE 考官式批改：分数、水平、逐条错误、改正版、母语者版
  - 语法手册、沉浸资源（RAE、Fundéu、RTVE、西班牙播客等）
- **复习**：间隔重复（SM-2），课程、查词、阅读、对话里收藏的词句都会进入复习
- **我的**：连续天数、经验、7 天统计、每日提醒、语速、AI 设置、个人背景（让 AI 举例更贴近你）

## AI 设置

「我的 → AI 设置」里选服务、粘贴 API Key，点「保存并测试连接」。

| 服务 | 说明 |
|---|---|
| Claude | 西语质量最好（默认 claude-sonnet-5-5，快速任务用 claude-haiku-5-5）；国内需要代理 |
| DeepSeek | 国内直连，便宜（deepseek-chat） |
| 通义千问 | 国内直连（qwen-plus / qwen-turbo） |
| OpenAI / 自定义 | 任意 OpenAI 兼容接口，可填中转地址 |

API Key 存在系统钥匙串里，只会发给你选择的那个服务。

## 构建与安装

1. 把整个文件夹推到 GitHub 仓库的 `main` 分支
2. Actions 自动运行「Build IPA」（也可手动 Run workflow）
3. 在运行页面底部 Artifacts 下载 `Vamos-ipa`，解压得到 `Vamos.ipa`
4. 用自签工具安装

本地有 Mac：`brew install xcodegen && xcodegen generate`，用 Xcode 打开 `Vamos.xcodeproj`。

**发音更好听**：设置 → 辅助功能 → 朗读内容 → 声音 → 西班牙语（西班牙），下载「增强 / 高级」语音（最好下载一男一女，听力对话会用两个声音）。

## 目录

```
Vamos/
  AI/         AI 客户端（Anthropic / OpenAI 兼容，流式）、提示词、课程生成与缓存
  App/        入口
  Models/     课程结构、练习生成、对话
  Store/      学习进度、间隔重复
  Services/   语音朗读、语音识别、新闻 RSS、提醒
  Support/    主题、布局、答案与发音评分
  Views/      各页面（Exercises/ 题型，Tools/ 探索里的工具）
  Resources/  course.json（A1 手写课）、syllabus.json（A2–C2 大纲）、placement.json（分级测试）
```

改大纲只需要编辑 `syllabus.json`：每节课写清楚语法点、词汇主题、交际功能和文化要点，AI 会按它生成。
